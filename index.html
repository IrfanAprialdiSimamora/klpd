🔎 Lihat Isi Komunikasinya

Request Android
GET /api/mahasiswa

Android meminta data.

Query API → MySQL
SELECT * FROM mahasiswa;

Server meminta data.

Response API → Android
[{"nama":"Andi","jurusan":"RPL"}]

Data dikirim sebagai JSON.
